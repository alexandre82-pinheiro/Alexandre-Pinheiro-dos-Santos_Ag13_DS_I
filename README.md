## 📌 Sobre o projeto

O **Meu Portal de Entretenimento Digital** é um projeto desenvolvido com o objetivo de apresentar conteúdos relacionados ao universo do entretenimento e da tecnologia, utilizando conceitos fundamentais de desenvolvimento web.

A página foi organizada em três seções principais:

- 🎥 **Filmes e Séries:** conteúdos sobre cinema, lançamentos e produções audiovisuais.
- 🎧 **Música e Podcasts:** conteúdos relacionados à música, artistas, playlists e podcasts.
- 🎮 **Games e Tecnologia:** informações sobre jogos, inovação, inteligência artificial e tecnologia.

O projeto busca apresentar uma página organizada, visualmente agradável e de fácil navegação.

## 💻 Tecnologias utilizadas

As tecnologias utilizadas no desenvolvimento foram:

- **HTML5:** responsável pela estrutura e organização dos elementos da página.
- **CSS3:** utilizado para definir cores, fontes, espaçamentos, bordas e aparência visual.
- **CSS Reset (Eric Meyer):** utilizado para normalizar as configurações padrão dos navegadores.
- **Flexbox:** utilizado para organizar os conteúdos em colunas e alinhar os elementos.
- **GitHub:** plataforma para armazenamento e compartilhamento do projeto.

## 🚀 Como executar o projeto

1. Faça o download ou clone o repositório.
2. Extraia os arquivos, caso estejam compactados.
3. Verifique se os arquivos HTML, CSS e as imagens estão na mesma pasta, respeitando os caminhos utilizados no código.
4. Localize o arquivo `index.html`.
5. Clique duas vezes no arquivo ou abra-o em um navegador de internet, como Google Chrome, Microsoft Edge ou Firefox.

Não é necessário instalar programas adicionais ou configurar um servidor para visualizar a página.

## 🎨 Recursos e conceitos aplicados

Durante o desenvolvimento foram utilizados:

- Estrutura semântica do HTML5.
- Aplicação de CSS Inline, Interno e Externo.
- Seletores por classes e IDs.
- Organização de elementos com Flexbox.
- Inserção de imagens com descrições alternativas.
- Comentários para facilitar a compreensão do código.
- Personalização visual com cores, sombras, bordas e espaçamentos.

## 🎯 Objetivo de aprendizagem

Este projeto foi desenvolvido como atividade prática de aprendizagem, com a finalidade de aplicar os conhecimentos de HTML5 e CSS3 na construção de uma página web.

A atividade também proporcionou o contato com conceitos de organização de código, estruturação de documentos e utilização de ferramentas de Inteligência Artificial como apoio ao aprendizado.

## 👨‍💻 Considerações finais

O desenvolvimento do portal permitiu compreender melhor como HTML e CSS trabalham juntos na construção de páginas web.

Além de praticar a organização de elementos e a estilização de interfaces, o projeto contribuiu para desenvolver o raciocínio lógico e a capacidade de analisar e melhorar códigos.
